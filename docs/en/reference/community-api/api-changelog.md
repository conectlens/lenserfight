# API Changelog

Community API changes (new RPCs, DTO changes, breaking contract changes) are recorded
as entries in the platform [Product Changelog](../../changelog.md), tagged with the `api`
scope, alongside every other user-facing change — not in a separate log here.

For everything merged to `main` that touches the API, including work that hasn't
shipped yet, see [Main Branch Activity](../../changelog/main.md).
